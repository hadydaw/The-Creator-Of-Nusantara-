# Pulau Kabut

Game farming dan simulasi hidup 3D sudut pandang orang pertama untuk Android (Godot 4.4, gaya low-poly).

Bertani, memancing (pasang surut memengaruhi tangkapan), dan jual hasil di warung. Setiap panen menipiskan kabut yang menyelimuti pulau.

## Unduh
APK terbaru ada di tab **Releases**. Pasang di Android (izinkan instalasi dari sumber lain).

## Kontrol
- Joystick (sentuh sisi kiri): jalan
- Geser sisi kanan: melihat
- Tombol Cangkul / Ember / Benih / Pancing: pilih alat
- AKSI: gunakan alat pada yang diarahkan kursor

Di PC: WASD jalan, panah melihat, E aksi.

## Uji otomatis
`godot --path . -- --selftest --shots=/tmp/shots`
